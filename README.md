# Enigma UX (Beta)

A design audit in your browser: open a page, press **Analyse this page**, and see what's wrong and where, with proof for every finding. Built on Enigma UX (Karan Verma, MIT) with the Design Audit engine.

**Download the latest version:** see [Releases](../../releases/latest). Each release has the zip and the steps to install and test it.

Releases only: this repository holds the builds, not the source.
